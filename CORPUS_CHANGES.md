# Prompt-Injection Corpus Changes

## Summary

This branch migrates the prompt-injection evaluation corpus to taxonomy v2 and rationalizes file boundaries by gate and regeneration workflow.

Rows now use `surface` and required `directive_present`. Attack rows carry `carrier`, `technique`, and `goal`; FP-gate benign rows carry `fp_category`. File provenance, license, review state, predecessor mapping, and metric gate live in `manifest.json`.

## Reorganization

- Merged `gram_benigns.jsonl`, `operational_benigns.jsonl`, and `agent_fp_benigns.jsonl` into `curated_benigns.jsonl`.
- Merged `adversarial_fable.jsonl` and `adversarial_codex.jsonl` into `curated_adversarial.jsonl`; row `origin` records fable or codex authorship.
- Kept `litellm_extended.jsonl`, `mutations.jsonl`, `trajectory_twins.jsonl`, and `deepset.jsonl` separate because their regeneration workflows differ.
- Added each external import as its own file.
- Added `url_cue_benigns.jsonl` to balance reserved-domain URL cues in benign FP-gate rows.

Discarded rows: none. `discarded_rows.md` is generated by the migration script and currently records no exact duplicate or indefensible-label discards.
