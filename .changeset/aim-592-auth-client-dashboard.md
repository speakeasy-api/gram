MCP server settings now list the upstream credentials Speakeasy uses to reach the upstream: which kind each is, whether it is on, and which other servers share it. Admins can say whether the upstream needs credentials at all, turn a credential on or off, remove it from one server, and choose who can use it with Can use and Blocked rules that apply wherever the credential is used. Roles can allow or block each kind of upstream credential, and API keys show and edit the servers and credentials they may use.
