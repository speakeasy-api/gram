Choose All tools (live), All tools (frozen), or Specific tools when approving a gateway connection. Frozen and Specific tools stay fixed at consent and are served from a fast cache, so tool access is much faster; live discovery refreshes tools from the approved member servers. Adding a member or connecting a previously unavailable server requires new consent. Calls execute live and re-check access.

The organization gateway offers the same tool picker, across every project the person can reach.
