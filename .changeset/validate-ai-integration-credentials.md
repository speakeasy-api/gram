Verify AI integration credentials before storing them. A save that would start polling on an unanswered key or external scope probes every sync schedule the provider runs with the cheapest read that schedule already makes; a refusal from every schedule fails the save with the provider's own message and writes nothing, and a partial refusal saves while pausing just the refused schedules in the same transaction.
