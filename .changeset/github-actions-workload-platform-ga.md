GitHub Actions is now offered as a workload platform to every organization. The agent wizard, Command K and preselected setup links offer its guided setup, where before it stayed under Coming soon unless the `workload-platform-github-actions` feature flag was on for the organization. The flag is removed. The setup's workflow installs the latest stable speakeasyd, and every release from v0.1.54 supports GitHub Actions.
