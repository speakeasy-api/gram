Opening your organization's MCP gateway URL in a browser now shows a landing page instead of a blank "404 Not Found". Members see the server URL and steps to add the gateway to Claude Code, Claude, Codex, Cursor, VS Code, opencode, ChatGPT and other MCP clients. If you're not signed in, Speakeasy asks you to sign in and then brings you back to the page. People outside the organization still see "Not found". If the gateway isn't available, members see a message asking them to contact an organization admin.
