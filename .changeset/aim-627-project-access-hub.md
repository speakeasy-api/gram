Each project has its own Access Hub, under the project's Security and Policy section, for the platforms and access rules that apply to that project alone. The organization's Access Hub keeps managing the organization tier, and neither lists the other's rows. Workload identity requests take `project_scoped` to read or change the selected project's tier, including the Claude Tag guided setup and the token endpoints it offers.
