Members can now ask for time-based access. Requesting access opens a dialog that shows what is being asked for, asks how long it is needed (1 hour, 2 hours, 4 hours or end of day on the member's own clock) and takes an optional note for the administrators. The Access Requests tab shows what each requester asked for in a new "Wants it" column, and the decide dialog suggests the matching window, or offers the requester's own deadline.
