The Project Assistant now finds its tools with less overhead. Tool search sends the full tool catalog once per turn, no longer repeats schemas it already returned that turn, leaves the per-server tool lists out, and lists oversized schemas by name instead of returning them in full. The assistant's instructions now say which Platform MCP tools to start with for project health, failures, usage and recent activity, to say plainly when no tool reports what was asked, and to keep answers short.
