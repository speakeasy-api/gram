Gateways now offer each member server's feedback tool, under the member's qualified name (for example `linear--submit_feedback`), in direct, drill-down and code mode. A report sent through a gateway is filed against the member it names. Feedback tools are offered even on connections that approved only some of a member's tools, and they pass the same checks as the member's own tools, including a proxied member's kill switch.
