Gateways now offer the feedback tool of each member server built from an OpenAPI document or functions, under the member's qualified name (for example `orders--submit_feedback`), in direct, drill-down and code mode. A report sent through a gateway is filed against the member it names. Feedback tools are offered even on connections that approved only some of a member's tools, and they pass the same checks as the member's own tools. Remote and tunneled members are left as they are.
