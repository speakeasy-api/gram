Set up directory role mappings in bulk from the SSO tab. "Set up in bulk" lists every group and attribute value with no role yet, proposes an existing role with the same name or a new role named after it, shows what access reused roles bring, and lets admins give new roles no access or a copy of another role's grants. Attributes with too many values to set up in bulk are named so they can be mapped one value at a time. Role chips in the mappings table no longer collapse into "N roles" after a mapping is saved or removed.
