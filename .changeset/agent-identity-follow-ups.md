Wherever the dashboard shows work an agent did for someone, it now names both: the agent, and the person whose authority it borrowed, on a second line beneath. Naming only the person hid that a machine made the call; naming only the agent hid who was accountable. An agent that acted on nobody's behalf is still shown alone.

The agent setup wizard dropped its scope question, which offered a choice that changed nothing about what an agent could reach, and gained an **All servers** toggle in its place — which is how an agent that may use every server is actually described. Before, such an agent showed a warning and no way to see or change what it held. The last step is now called **Install**, since that is what it does.

An agent's overview page shows what the agent has been doing — tool calls over time, the servers it used most, and who it has been acting for — instead of restating its configuration.

Agent Sessions is a table with named columns. Activity and Messages sort from their own headers, ordering the whole list rather than the page in front of you, and the order is kept in the address so it can be shared.

The people list leaves out anonymous identities unless you ask for them, and every alert now says how serious it is.
