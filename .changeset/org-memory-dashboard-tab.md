Organizational Memory moves into Agent Sessions as its own tab, replacing the old Org Memory page. The tab shows month, week and day digests with the sessions and memos behind each one, and every citation opens the session it came from. The sessions table gains a Memory column, and the session sheet shows the masked summary agents read, the memos saved from it and a switch to keep the session out of memory. Old Org Memory links redirect to the new tab. Shown to organizations with the `org-memory` flag.
