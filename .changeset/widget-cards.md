The Widgets tab can draw each widget as a card. A List | Cards toggle switches views and is kept in the URL. Each card has the same actions as its row and runs its query only once it scrolls into view. Above the cards sits the dashboard's shared filter bar, offering only the fields (user, agent, model, MCP server, status) some widget can be filtered by:

- Each card keeps its own saved window until a date range is picked.
- A card opens in Explore as the question it ran.
