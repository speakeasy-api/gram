A skill's current version is now the version plugins ship. A version captured from someone's machine no longer shows as current in the dashboard, the share page, or Platform MCP while an uploaded version exists, and it no longer replaces the skill's summary. Version history marks captured versions and offers Promote on them. Suggested edits are diffed against the version they were written for, so the diff shows only the proposed changes. Dismiss now sits next to Apply all and Apply selected, and the Apply all dialog keeps its buttons on screen for long diffs.
