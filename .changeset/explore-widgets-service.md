Add the `widgets` service: Explore's saved questions, each kept with the chart that draws it, as the building block dashboards will place. Any member can list, get, save, update and duplicate a widget; duplicating is how a widget is shared, giving the caller their own copy. The question is validated against the catalog and the chart against the question, on save and again on read, so a catalog change fails visibly. Deleting someone else's widget needs project write access. Every change is audited.
