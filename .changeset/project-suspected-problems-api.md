The MCP connection health API lists a project's suspected MCP connection problems across all its MCP sign-ins, for the Project Overview. Problems are grouped and counted from the project's own failures, in the same order as an MCP sign-in's list. A problem names an MCP sign-in, and an MCP server, only when that page lists the same problem. Only people who can read every log in the project see them. The demo's daily provider refreshes now record their MCP sign-in, as production does.
