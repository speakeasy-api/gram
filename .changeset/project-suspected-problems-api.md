The MCP connection health API lists a project's suspected MCP connection problems across all its MCP sign-ins, for the Project Overview. Problems are grouped and counted from the project's own failures, in the same order as an MCP sign-in's list, and each names the MCP sign-in and MCP server whose pages list it. Only people who can read every log in the project see them. The demo seed's scheduled refresh sweep now only succeeds, so the demo project lists only its intended problems.
