An agent's Credentials tab is now called Agent sign-in, at `/sign-in`, and shows the same sign-in diagram as the creation wizard. Issue a key there now runs the creation wizard's own Agent sign-in, Install and Verify steps for the servers the agent already reaches. It no longer asks you to pick servers, connect accounts, or name the key and set its expiry. Old links to the Credentials, Provisioning and Devices sections of an agent now open Agent sign-in instead of "Identity not found".
