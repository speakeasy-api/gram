Every saved data export now has a Send test event button in its settings, for org admins. It sends a test event to the destination and shows the answer right there, such as a refused API key or a wrong URL. For product telemetry it sends a test log, trace and metric, and shows the answer for each. After a test, the dashboard shows the test event ID with a copy button, so you can find the test in your destination.
