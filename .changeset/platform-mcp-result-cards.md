Platform MCP tools now show an inline result card in clients that render MCP Apps, such as ChatGPT. Each card links to the matching dashboard page: an MCP server, plugin, skill, risk policy, gateway, dashboard, or the section list when the exact page cannot be named. Reads show the resource, lists show a count and the first few rows, changes show what was done, and refused or unavailable calls show the reason with a request-access link when there is one. Analytics, logs, and results meant for the model stay text-only. Clients without MCP Apps and the managed assistant see the same results as before.
