A new agent identity sends hook events by default. When its creator may grant it, the agent is created with hook ingestion in its project and its first key requests it; the Issue a key wizard offers it too, selected by default. Server selection is now optional: an agent created with no MCP server only sends hook events and syncs device-agent plugins, and the install step gives its key as the observability plugin's `SPEAKEASY_AI_HOOKS_*` environment instead of an MCP gateway setup link.
