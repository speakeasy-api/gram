Organization admins can create an organization-wide sign-in from the Speakeasy sign-ins page. It asks how people log in: Speakeasy login is created right there, and Okta points to the Okta sign-in setup. If one already exists, the admin has to confirm first, because a second one turns off the organization gateway. "Make organization-wide" is removed; "Consolidate into another" covers moving a project's servers onto an organization-wide sign-in. The page now says "sign-ins" throughout, and the organization gateway links here when it is missing a sign-in or has too many.
