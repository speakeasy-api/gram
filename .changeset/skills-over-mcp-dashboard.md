Behind the `skills-over-mcp` flag, MCP server and gateway pages gain a Skills tab that lists the skills linked to them, with when each was last loaded over MCP, and lets writers add project skills or stop serving one. The skill page gains a "Served over MCP" section listing the servers and gateways that serve the skill, with its served digest and an action to add it to the organization gateway.
