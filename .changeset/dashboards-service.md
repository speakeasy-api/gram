Add the `dashboards` service: a project's layouts of saved widgets on a 12-column grid. Any member can create a dashboard, lay out its cards (each chart type has a minimum size), place or remove saved widgets, and save the date range and filters it opens on; editing or deleting someone else's needs project write access. Widgets are linked, not copied, so editing one changes it on every dashboard. Duplicating a dashboard copies its widgets into new saved widgets, so the copy is independent. Every change is audited.
