Organization admins can enable Enterprise Managed Authorization from a Speakeasy card on IDP and SSO › Identity providers: copy the issuer URI to register with supported services, disable it with an explanation of the effect, replace a compromised signing key, or finish setting up a new key after one was withdrawn. If a replacement key can't be set up, the card says so instead of reporting success. The issuer now also checks that it belongs to the deployment serving it before it signs or can be enabled.
