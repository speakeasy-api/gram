Under upstream auth enforcement, a personal connection its owner attached to an agent now serves that agent whoever issued its API key. Attaching is the owner's consent. The owner's live policy, the key issuer's and the agent's must all still allow the connection, and detaching, owner blocks, the owner leaving and agent suspension still stop use at once. An agent key with no attachment still uses only its issuer's own connection.
