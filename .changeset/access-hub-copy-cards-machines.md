The Access Hub reads more plainly. The page opens with a one-line summary of what it is for, and each platform card shows only its name, description (or issuer URL) and tags. On a platform's page the issuer and keys URLs sit on labeled lines of their own, machine tags get their own column, and the machines table shows ten rows a page. Allowing a machine is now "Allow access", withdrawing one is now "Remove", and "Stop trusting" moves out of the header into a danger-zone section below the machines.
