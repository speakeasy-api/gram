Platform MCP shows an inline card in apps that render MCP Apps, such as ChatGPT and Claude. Adding an MCP server to a project shows the server, its project, that it stays private until it is added to a plugin, and the next step. Connecting a server's sign-in provider shows one "Sign in to <name>" button. Apps that do not render MCP Apps get the same text and structured results as before.
