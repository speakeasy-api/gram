When a gateway member can't list its tools, the connect page now names why for rate limits, server errors, no answer, a rejected shared credential, a misconfigured connection and a down tunnel; other causes keep the generic card. Connection health records the same cause a tool call on that member would, naming the member's upstream host only when the upstream itself failed. Running out of the gateway listing's own time still reads as a member whose tools are missing. Listing rows never count toward provider health.
