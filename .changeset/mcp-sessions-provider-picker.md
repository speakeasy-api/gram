MCP Sessions opens on one MCP Authentication Provider, chosen from the picker in the page header, with its session length and client access beside the name. Its tabs are Connections (the sessions signed in through that provider), MCP servers (the servers and gateways that use it), and Settings (session length, client access, Enterprise Managed Auth, advanced details, and actions such as Make organization-wide). The page remembers the last provider you opened. Links to the old Configuration tab and provider pages still work.
