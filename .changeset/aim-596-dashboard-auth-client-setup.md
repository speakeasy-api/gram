MCP server settings let administrators add upstream credentials: reuse one another server already offers, or create a service account, a static credential, a caller-supplied header or each person's own account. A credential's sheet edits and rotates its headers, and warns before a change that applies on other servers. The static Authorization identity choice is now called a shared credential, with "Static credential" and "Service account" as its formats. Agent pages list the credentials an agent may not use: agent managers block a kind of credential or one credential, and anyone can block the agent from their own connections.
