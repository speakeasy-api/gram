Add Code Mode discovery for MCP gateways. A single execute tool runs ephemeral Python with live search, schema descriptions and authorized calls to hosted, remote and tunneled tools. Settings, consent and Inspect support the new mode, including frozen toolsets, explicit connection overrides, execution results and nested-call outcomes.

New selections require discovery entitlement, rollout availability and a configured isolated OSS Monty runtime. Existing code-mode connections retain their meaning when rollout is disabled.
