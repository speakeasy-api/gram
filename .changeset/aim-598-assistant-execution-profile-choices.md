Assistants now show and let you choose which upstream credential they use on each MCP server they reach, under each trigger, separately for turns that act for a person and turns that act for nobody. Open an assistant, then **Identity** → **Upstream credentials**. Servers that offer several credentials say so until one is chosen. Turns already running keep the credential they started with. Turns that act for nobody can use shared credentials only. Each change is recorded in the audit log.
