A warn policy that fires through Anthropic inference hooks now gives the user a way to unblock itself. The denial carries the same acknowledgement link the local hook transports mint, so the warned user can approve the held action from the dashboard and retry; previously the protocol's single `deny_reason` channel made a warn indistinguishable from an unappealable block. An approval clears only that user's identical retry of the same call and lets the conversation continue; an unresolved actor, or an unavailable link, still denies rather than allowing.
