A gateway tool call refused because a server's sign-in or settings changed since approval now names the server and says whether reconnecting fixes it or an administrator must. Describing the server, its connection status and Code Mode give the same answer. Connection health records the administrator case as `approval_needs_admin`. The gateway consent page now lets a person choose between two connected services for one server when sign-in enforcement is off, instead of showing it as not set up.
