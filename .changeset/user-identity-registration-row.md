Redesign how a remote MCP server's User Identity client is shown and changed. A connected client reads as "Connected" with how many people are signed in and its scopes, plus an Advanced link to the client. Clearing it offers an existing client, Auto-Configure or Manual credentials. Auto-Configure can choose between CIMD and DCR when the provider supports both, Manual can set scopes, and replacing a client asks first because everyone has to sign in again.
