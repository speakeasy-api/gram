The External MCP migration page now lists every toolset still backed by an external MCP attachment, including ones to delete: toolsets with MCP off and no server, toolsets whose attachment is no longer on the active deployment, toolsets that proxy more than one upstream, and toolsets that were already migrated. Staff can delete those from the page, with the same preview first; deleting removes the toolset with its server, addresses and plugin entries, and leaves an already migrated server untouched.
