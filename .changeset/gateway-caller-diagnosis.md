Gateway connection health can now be read for one person or agent and the registered client they used. Each stage is counted for them alone, with every provider and with attempts that recorded none, and their provider sign-ins and refreshes are listed per provider, successful ones included, with no attempt floor and a note when more providers exist than are listed. A listing's detail shows this beside the stale listing: the sign-in token responses written, and each provider's saved credentials and refreshes in the same window, as observations rather than causes. The Platform MCP connection health tool accepts the same caller.
