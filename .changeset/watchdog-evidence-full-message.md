Watchdog evidence cards can now show the message behind a finding. In the signal drawer, the session title on each card expands in place to the full message the finding was flagged in, opens the session transcript with its flagged messages in focus, and links to the session in Agent Sessions. Flagged secrets and PII stay masked in the expanded message. These controls only appear for users with the `chat:read` scope.
