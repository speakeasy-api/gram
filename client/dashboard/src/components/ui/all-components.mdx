# All components

Every component in `components/ui`, on one page, so the design-system
components internalised from Moonshine can be compared side by side with the
ones Gram already had. Each entry is tagged with where it came from:

- **DS** — internalised from the Moonshine design system.
- **Gram** — written for the dashboard.

Flip the theme with the toolbar's theme switcher to check both palettes.

Docs pages do not run the preview decorators, so each row supplies the
providers its components expect.

export const Row = ({ name, origin, children }) => {
  const [theme, setTheme] = useState("light");

  return (
    <ConfigProvider theme={theme} setTheme={setTheme}>
      <TooltipProvider>
        <div className="flex flex-col gap-2 border-b py-6 last:border-b-0">
          <div className="flex items-center gap-2">
            <span className="font-mono text-sm">{name}</span>
            <span className="text-muted-foreground border px-1 font-mono text-[10px] uppercase">
              {origin}
            </span>
          </div>
          <div className="flex flex-wrap items-center gap-4">{children}</div>
        </div>
      </TooltipProvider>
    </ConfigProvider>
  );
};
